## 一、安装

### Mac

1. 打开 `Aurio-<版本>.dmg`，把 Aurio 拖到「应用程序」文件夹，然后从「应用程序」中打开它。菜单栏会出现 Aurio 图标（五根竖条）。
2. 第一次运行时，macOS 会询问是否允许 Aurio 访问「本地网络」，请选择**允许**，否则收不到 Windows 的数据。
3. 第一次有 Windows 应用使用麦克风时，macOS 会询问麦克风权限，请选择**允许**。

### Windows

1. 运行 `Aurio-Setup-<版本>.exe`，按提示选择安装位置，以及是否创建桌面快捷方式、是否开机自启。
   - 安装包没有代码签名，Windows 可能提示「Windows 已保护你的电脑」。点「更多信息」→「仍要运行」即可。
   - 如果系统缺少 Microsoft WebView2 运行时，安装程序会提示并打开微软的下载页面。
   - 不想安装的话，也可以用免安装版 `Aurio-Windows.zip`，解压后直接运行 `Aurio.exe`。
2. 安装虚拟声卡驱动（只有麦克风功能需要）：打开 Aurio →「设置」→「虚拟声卡驱动」→「安装驱动」。
   - Aurio 会从 VB-Audio 官网下载 VB-Cable 官方安装包，校验数字签名后静默安装。过程中会弹出一次 Windows 管理员确认框。
   - 安装完成后，Aurio 会把默认录音设备设为「CABLE Output」，应用默认就会用上 Studio Display 的麦克风。
   - 部分情况下需要重启电脑，驱动才能完全生效，界面会给出提示。

## 二、连接

1. 确认 Mac 上的 Aurio 已经打开。
2. 打开 Windows 上的 Aurio，主页会自动搜索局域网里的 Mac：
   - 只找到一台时自动选中；有多台时，点 Mac 名称旁的箭头选择。
   - 搜索不到时，可以在「设置 → Mac → 手动地址」里填写 Mac 的 IP，例如 `192.168.1.20`。
3. 点「连接」。右上角状态变成「已连接」后，Windows 的声音就会从 Studio Display 播放。

Aurio 会采集 Windows 的**默认播放设备**。如果这个设备本身接了扬声器，Windows 本地和 Studio Display 会同时出声。建议把默认播放设备设为一个不出声的设备，例如没有接喇叭的显示器 HDMI 音频。「设置 → 设置检查」会检查这些设置，大部分问题可以点「一键修复」自动处理。

## 三、Mac 菜单栏面板

点菜单栏的 Aurio 图标打开面板。图标为实心表示已连接，变淡表示还没连上。

| 区域 | 说明 |
|---|---|
| 状态 | 显示「正在播放 Windows 的声音」及对方 IP、当前延迟；Windows 端已连接但没有声音时显示「已连接 Windows · 没有声音」 |
| 麦克风 / 回声消除 | 两个快捷开关。点「麦克风」在「关闭」和「自动」之间切换；点「回声消除」开关回声消除（见[第五节](#五回声消除)） |
| 扬声器 | 点右侧的设备名可以换输出设备，默认自动选择 Studio Display。拖动白色音量条调整音量，下方是实时电平 |
| 麦克风 | 点右侧的设备名可以换输入设备。模式：**自动**（Windows 上有应用录音时才打开麦克风）、**常开**、**关闭** |
| 底部 | 延迟、缓冲、时钟修正（ppm）、欠载四项指标（见[第六节](#六指标说明)）；「登录时打开」；「退出 Aurio」（⌘Q） |

## 四、Windows 界面

窗口底部有三个页面：

**连接**
- 上方卡片：当前 Mac、连接状态、往返时间、发送包速率、麦克风缓冲，以及「连接 / 断开连接」按钮。
- 扬声器和麦克风的实时电平。Mac 端正在做回声消除时，麦克风旁会显示「回声消除」标签。

**录音测试**：检查 Studio Display 外放的声音会不会漏进它自己的麦克风，也就是通话时对方会听到的回声。
1. 先连接 Mac，并把麦克风模式设为「自动」或「常开」。
2. 在 Windows 上播放音乐或打开游戏，选择录音时长后点「开始录音」。
3. 录音结束后会显示回声延迟、回声强度（相对播放声音的 dB，越低越好），以及录音中回声的占比。
4. 可以直接回放录音，录音同时以 WAV 文件保存在「下载」文件夹。

测试录到的是应用实际收到的声音：Mac 端开着回声消除时，结果就是消除之后的效果。

**设置**
- **Mac**：已发现的 Mac 列表和手动地址。
- **声音**：播放来源（默认采集系统默认播放设备）、麦克风模式、打开 Aurio 时自动连接。连接期间不能修改播放来源和麦克风模式。
- **窗口**：关闭窗口时的行为，见下文。
- **虚拟声卡驱动**：安装或卸载 VB-Cable。
- **设置检查**：检查默认播放 / 录音设备和采样率等设置，提供「一键修复」和「打开声音设置」。

### 关闭窗口与托盘

- 第一次点窗口右上角的 ×（或按 Alt+F4）时，Aurio 会询问：
  - **最小化到托盘**：窗口隐藏，Aurio 在后台继续传送声音和麦克风。
  - **退出 Aurio**：停止传送并关闭程序。

  勾选「记住我的选择，不再询问」后，以后会直接按这个选择执行。
- 随时可以在「设置 → 窗口 → 关闭窗口时」改为「每次询问」「最小化到托盘」或「退出 Aurio」。
- 托盘图标：左键单击打开窗口，右键菜单提供「打开 Aurio」和「退出 Aurio」。图标会跟随任务栏的浅色 / 深色主题切换为黑色或白色，没有连上 Mac 时图标变淡。
- 安装时选择了开机自启的话，开机后 Aurio 直接在托盘中运行，不弹出窗口。
- Aurio 同一时间只运行一个实例。程序在托盘中时再次打开 Aurio，会直接显示已有的窗口。

## 五、回声消除

外放时开麦，扬声器里的声音（例如游戏声）会被麦克风收进去，对方就会听到。打开 Mac 面板上的「回声消除」后，Windows 上有应用开始使用麦克风时，Mac 会切换到系统的语音处理，也就是 FaceTime 使用的同一套回声消除、降噪和自动增益，并使用 Studio Display 的整个麦克风阵列。因为它知道扬声器正在播放什么，可以把这部分从麦克风信号中减掉。

- 默认关闭。外放并且需要开麦时建议打开；只用耳机或不开麦时不需要。
- 打开回声消除的这段时间，播放会变成通话音质。麦克风停用约 3 秒后自动恢复原始音质。
- 切换的瞬间声音会中断一下。

## 六、指标说明

| 指标 | 位置 | 含义 | 参考值（有线局域网） |
|---|---|---|---|
| 延迟 | Mac | 从收到数据到 Studio Display 发声的时间，包括显示器自身固定的 22 ms | 35–45 ms |
| 缓冲 | Mac | 当前缓冲中的数据量。Windows 每 10 ms 送来一批数据，所以这个值会在「安全余量」和「安全余量 + 10 ms」之间来回变化，属于正常现象 | 5–20 ms |
| ppm | Mac | 两台电脑时钟快慢的差异，Aurio 会持续校正。刚连接时可能较大，几分钟后会稳定 | 几十到几百 |
| 欠载 | Mac | 缓冲用完导致的短暂断音次数。连接初期或网络抖动时偶尔出现属于正常 | 长时间运行基本不增长 |
| 往返 | Windows | 心跳从 Windows 到 Mac 再返回的时间 | 小于 2 ms |
| 麦克风缓冲 | Windows | 麦克风方向的缓冲量 | 几毫秒 |

鼠标悬停在 Mac 面板的指标上，可以看到目标缓冲、包速率和最大包间隔等详细数据。缓冲会根据网络和系统调度的抖动自动调整：抖动越大，留的余量越多。

## 七、常见问题

**Mac 面板一直显示「等待 Windows 连接」**
- 检查「系统设置 → 隐私与安全性 → 本地网络」中 Aurio 是否已开启。
- 确认 Windows 上已经点了「连接」，并且选择的是这台 Mac。
- 端口 47800 被占用时，面板会直接提示（例如同时运行着命令行版 `aurio-rx`）。

**Windows 显示「Mac 没有响应」**
- 两台电脑可能不在同一网络，或 Mac 上的 Aurio 没有运行、没有「本地网络」权限。
- 检查路由器或防火墙是否拦截了 UDP 47800 端口。

**Studio Display 没有声音，但已经显示「已连接」**
- 看 Windows 主页的扬声器电平是否在跳动。不跳说明 Windows 没有往被采集的设备播放声音，请检查默认播放设备，或在「设置 → 声音 → 播放来源」中指定设备。
- 检查 Mac 面板的音量和输出设备。

**应用里录不到声音**
- 确认已经安装虚拟声卡驱动，并且应用里选择的麦克风是「CABLE Output」。
- 确认麦克风模式不是「关闭」，并在「系统设置 → 隐私与安全性 → 麦克风」中允许 Aurio。
- 运行「设置 → 设置检查」，按提示修复。

**系统声音直接进了麦克风**

默认播放设备被设成了「CABLE Input」。请改为其他播放设备，或在「设置检查」中点「一键修复」。

**对方听到回声**

打开 Mac 面板上的「回声消除」。会议软件通常也自带回声消除。

**偶尔有爆音**

查看 Mac 面板的欠载数是否持续增长。如果持续增长，尽量改用有线网络，并关闭占用大量 CPU 的后台任务。

## 八、卸载

**Windows**：开始菜单 →「卸载 Aurio」，或在「设置 → 应用」中卸载。
- 卸载程序会先检测虚拟声卡驱动。如果检测到，会先把驱动彻底卸载，再删除 Aurio。
- 可以选择是否同时删除设置。
- 卸载完成后需要重启电脑才能完全生效，最后一页可以选择立即重启。

**Mac**：在菜单栏面板点「退出 Aurio」，然后把 `Aurio.app` 移到废纸篓。

## 附录：命令行与环境变量

日常使用不需要以下内容，它们用于排查问题。

**Windows 命令行版**（`aurio-win.exe`，在安装目录或免安装版中）

| 命令 | 作用 |
|---|---|
| `aurio-win setup` | 检查 VB-Cable 和声音设置 |
| `aurio-win discover` | 搜索局域网中的 Mac |
| `aurio-win send [--to IP]` | 开始传送（不指定 `--to` 时自动搜索 Mac） |
| `aurio-win list` | 列出音频设备、格式和引擎周期 |

`send` 的常用选项：`--loopback 名称`（采集指定的播放设备）、`--mic auto|on|off`、`--mic-queue-ms N`（麦克风写入队列余量，默认 5 ms，偶尔爆音时可调大）。

**Windows 图形界面参数**：`Aurio.exe --tray` 表示启动后直接进入托盘，开机自启使用的就是这个参数。

**Mac 命令行版**（`aurio-rx`，见 [DEVELOPMENT.md](DEVELOPMENT.md)）

| 命令 | 作用 |
|---|---|
| `aurio-rx list` | 列出输出和输入设备 |
| `aurio-rx run [选项]` | 接收并播放。选项：`--device 名称`、`--mic auto\|on\|off\|tone`、`--mic-device 名称`、`--port N` |

从终端运行 `aurio-rx` 时，需要在「本地网络」权限中允许该终端程序，否则收不到数据。

**Mac App 环境变量**

| 变量 | 作用 |
|---|---|
| `AURIO_PORT=N` | 使用其他 UDP 端口 |
| `AURIO_MUTE=1` | 音量固定为 0，且不保存音量设置（测试用） |
| `AURIO_MIC_TONE=1` | 不打开麦克风，改为发送 440 Hz 测试音，用于检查麦克风链路 |
