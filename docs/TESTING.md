# 测试与验收

## 1. 自动测试

每次修改核心库后运行：

```bash
cargo test --release -p aurio-core
```

修改缓冲、漂移补偿或重采样相关代码后，再跑一次长时间仿真，确认没有欠载：

```bash
./target/release/aurio-sim --hours 24 --ppm 80 --jitter-ms 2
```

```bash
./target/release/aurio-sim --hours 24 --ppm -120 --jitter-ms 4 --loss 0.001
```

第二组条件比有线局域网恶劣得多，允许出现个位数的欠载。

修改 Mac 界面后，可以用快照模式检查渲染效果，不需要打开音频。先创建输出目录：

```bash
mkdir -p /tmp/aurio-snap
```

```bash
AURIO_SNAPSHOT=/tmp/aurio-snap dist/Aurio.app/Contents/MacOS/Aurio
```

目录中会生成「正在播放」「等待连接」两种状态的面板截图，以及菜单栏图标。

## 2. 真机验收清单

发布前在真实的 Windows 电脑和 Mac 上逐项检查。建议使用一台干净的 Windows（或先卸载旧版本），并用有线网络连接。

### 2.1 Windows 安装

- [ ] 运行安装包，可以自定义安装位置，桌面快捷方式和开机自启可选
- [ ] 安装完成后，开始菜单中有「Aurio」和「卸载 Aurio」，图标正确
- [ ] 缺少 WebView2 运行时的电脑上，安装程序会给出提示
- [ ] 安装时如果 Aurio 正在运行，会先把它关闭

### 2.2 虚拟声卡驱动

- [ ] 「设置 → 虚拟声卡驱动 → 安装驱动」：只弹出一次 UAC 确认框，安装完成后状态显示「已安装」
- [ ] 安装后默认录音设备自动变为「CABLE Output」
- [ ] 以普通权限和管理员权限分别打开 Aurio，都能完成安装
- [ ] 「卸载驱动」：设备管理器和声音设置里不再出现 CABLE 设备；需要重启时界面给出提示

### 2.3 连接与播放

- [ ] Mac 打开 Aurio 后，Windows 主页能自动找到它；手动填写 IP 也能连接
- [ ] 点「连接」后状态变为「已连接」，往返时间小于 2 ms（有线）
- [ ] 先连接、后播放声音：开始播放时 Studio Display 立刻出声，Mac 面板一直显示已连接，中间不会出现「已断开」
- [ ] 不播放声音时，Mac 面板显示「已连接 Windows · 没有声音」，菜单栏图标保持实心
- [ ] Mac 面板的延迟在 35–45 ms，ppm 在几分钟内稳定
- [ ] 连续运行 2 小时以上（包括打游戏），欠载数基本不增长
- [ ] Windows 断开连接或退出后，Mac 面板几秒内显示「连接已断开」，菜单栏图标变淡

### 2.4 麦克风

- [ ] 模式为「自动」：Windows 应用开始录音时 Mac 打开麦克风，停止录音约 3 秒后关闭
- [ ] 模式为「常开」和「关闭」时行为正确
- [ ] 应用中选择「CABLE Output」，能录到 Studio Display 麦克风的声音，Windows 主页和 Mac 面板的麦克风电平都会跳动
- [ ] 第一次使用麦克风时，macOS 会询问权限；拒绝后面板给出提示

### 2.5 回声消除

- [ ] 外放游戏或音乐并开麦，打开回声消除后，「录音测试」的回声强度明显下降
- [ ] Windows 主页麦克风旁显示「回声消除」标签
- [ ] 麦克风关闭后约 3 秒，播放恢复原始音质

### 2.6 托盘与窗口

- [ ] 第一次点 × 时弹出询问框，「最小化到托盘」「退出 Aurio」「取消」都正常
- [ ] 勾选「记住我的选择」后不再询问；「设置 → 窗口」中显示对应选项，改回「每次询问」后会重新询问
- [ ] Alt+F4 和任务栏右键关闭的行为与点 × 相同
- [ ] 托盘图标：左键打开窗口，右键菜单的「打开 Aurio」「退出 Aurio」正常
- [ ] 在「设置 → 个性化 → 颜色」中切换 Windows 模式（浅色 / 深色），托盘图标在几秒内跟着切换
- [ ] 没有连上 Mac 时托盘图标变淡，悬停提示显示当前状态
- [ ] 程序在托盘中时再次打开 Aurio，只会显示已有窗口，不会出现第二个进程
- [ ] 开启开机自启后重启电脑：Aurio 直接在托盘中运行，不弹窗口；开启了「打开 Aurio 时自动连接」的话会自动连接

### 2.7 Mac 面板

- [ ] 打开、关闭面板多次，电平条每次都正常跳动
- [ ] 切换麦克风模式、开关回声消除后，面板高度随内容变化，没有多余的空白或背景错位
- [ ] 点设备名能弹出设备菜单，切换输出 / 输入设备后正常工作
- [ ] 拖动音量条流畅，重启 App 后音量保持
- [ ] 「登录时打开」开关生效
- [ ] 拔掉再插上 Studio Display，播放自动恢复

### 2.8 卸载

- [ ] 卸载时检测到驱动，会先卸载驱动再删除 Aurio
- [ ] 可以选择是否删除设置
- [ ] 卸载完成后提示重启；重启后系统中不再有 Aurio 的文件、开机自启项和 CABLE 设备

## 3. 已知限制

- Windows 程序和安装包没有代码签名，首次运行会出现 SmartScreen 提示。
- Mac App 没有做公证，只适合在自己的设备上使用。
- 延迟下限受 Studio Display 的 22 ms 硬件延迟和 Windows 共享模式 10 ms 采集周期限制。
- Studio Display 的 22 ms 是驱动报告的值，还没有用声学方法实测核实。
